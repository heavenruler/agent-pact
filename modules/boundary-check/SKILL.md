# Boundary Check

此模組只增加限制，不授權繞過既有政策、權限系統或 hook。清單按目標、身分、環境、政策版本綁定；任一改變即重新產出。

首次碰新主機、資料庫或 repo 時產出清單。遠端異動、破壞性操作、敏感資料外傳、自改治理設定、跨 session 操作前重新對照。

輸入：目標、身分、環境及其證據、動作、敏感度、現有授權、hook/權限能力、政策版本。未知環境當正式環境；未知授權視為無授權；未知攔截視為無攔截。只允許唯讀調查來補足未知。

```text
邊界清單：目標=… 身分=… 環境=… 政策=…
強制攔截：有（機制）／無（只有操作前檢查）
能做：…（授權來源）
要問：…（影響及還原）
不碰：…（理由）
```

正式、災備或未知環境的寫入列「不碰」。敏感值不得原文外傳。修改自身安全邊界列「不碰」，可寫提案供人審核。找不到事件紀錄不等於允許。沒有 hook 時明說「只有操作前檢查，無強制攔截」，「要問」動作暫停等待使用者。不得替其他 session 回答安全確認框。
